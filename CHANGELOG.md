# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-01-01

### Added

- Initial release
- Core gem structure with Rails engine
- Installation generator (`rails g shadcn:install`)
- Component generator (`rails g shadcn:component`)
- JavaScript generator (`rails g shadcn:js`)
- 19 UI components:
  - Button
  - Card
  - Input
  - Textarea
  - Select
  - Checkbox
  - Switch
  - Label
  - Badge
  - Alert
  - Dialog
  - Dropdown Menu
  - Avatar
  - Tabs
  - Tooltip
  - Separator
  - Skeleton
  - Spinner
  - Progress
- ViewHelpers for class merging (`cn` helper)
- TagHelper for convenient component rendering
- FormBuilder integration
- Stimulus controllers for interactive components
- Tailwind CSS configuration with shadcn variables
- Comprehensive documentation
